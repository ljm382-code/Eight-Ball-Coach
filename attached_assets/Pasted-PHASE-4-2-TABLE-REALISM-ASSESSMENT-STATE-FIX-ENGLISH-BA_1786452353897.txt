This patch addresses ONLY THREE issues:

==================================================
1. FIX POOL-BALL PROPORTIONS
==================================================

The current SVG table renders balls much too large.

Use realistic English-pool proportions.

Visual reference:

English pool ball diameter ≈ 2 inches / 50.8 mm
Typical English pool table ≈ 6 × 3 ft

Therefore ball diameter should visually represent approximately:

2.8% of the table playing length

or approximately:

5.5% of the table playing width.

Do not use an oversized arbitrary fixed radius.

Derive ball radius from the reusable PoolTable/table geometry.

Example:

If the table playing-surface SVG width is around 300 units:

ball diameter ≈ 8–9 units
ball radius ≈ 4–4.5 units

Adjust proportionately for the actual current SVG viewBox.

The result should look like real English pool balls placed on a full-size table, not oversized tokens.

10. FIX ASSESSMENT FAILURE-STATE LEAK
==================================================

There is a UI bug in Initial Assessment.

Current incorrect flow:

Question 1
→ player taps FAILED
→ failure reasons appear
→ player selects MISS / POSITION / SPEED / etc.
→ assessment advances to Question 2
→ Question 2 incorrectly still shows failure-reason options

Correct flow:

Question 1
→ SUCCESS or FAILED

If FAILED:
→ show failure classification
→ player selects one reason
→ record failure + classification
→ advance

Question 2
→ fresh default state
→ SUCCESS or FAILED

Every assessment item must begin in its normal initial interaction state.

11. RESET TRANSIENT DRILL UI STATE
==================================================

Audit the current DrillRunnerItem / Assessment integration.

Transient state such as:

- showErrorGrid
- selected error
- decision feedback
- temporary selection
- local feedback state

must reset whenever the active drill/assessment item changes.

Use a robust React solution.

Acceptable approaches:

A. Ensure runner components have unique keys based on drill/item ID so they remount cleanly for every item.

AND/OR

B. Explicitly reset transient state whenever drill.id changes.

Example conceptually:

useEffect(() => {
  setShowErrorGrid(false);
  setFeedback(null);
}, [drill.id]);

Do not rely on timing/order of asynchronous React state updates.
