3. WPA BLACKBALL TABLE REFERENCE
==================================================

For Blackball training diagrams, support:

BAULK LINE
- transverse line across the playing surface
- positioned 1/5 of the playing length from the baulk cushion

BLACK SPOT
- clearly marked spot for the black
- located at the intersection of the imaginary diagonals running from the centre pockets to the opposite corner pockets

When a drill discusses baulk, visibly identify:

BAULK

with a subtle shaded region or small label.

Do not clutter every normal drill with the label if it is irrelevant.

4. INTERNATIONAL RULES TABLE REFERENCE
==================================================

For International Rules training diagrams, support:

BREAK LINE
- parallel to the baulk cushion
- 1/5 of the table length from the baulk cushion

RACK LINE
- longitudinal line approximately 280mm through the eight-ball/black spot toward the top cushion

HEAD-BALL MARKER
- marker point on the rack line

BLACK / EIGHT-BALL MARKER
- marker point on the rack line

Use these where relevant to:
- break setup
- rerack/rack instruction
- black positioning
- rules scenarios

20. CUE BALL TYPE MUST BE AUTHORITATIVE
==================================================

Fix cue-ball representation at the model/rendering level.

Do NOT infer cue ball by arbitrary colour.

Every training diagram must represent it explicitly as:

group/type: "cue"

The renderer MUST map:

cue → BALL.cue / #F2F0E8

unconditionally.

Any supplied display colour for a cue ball must be ignored.

Conceptually:

function resolveBallColor(ball) {
  switch (ball.group) {
    case "cue":
      return BALL.cue;
    case "red":
      return BALL.red;
    case "yellow":
      return BALL.yellow;
    case "black":
      return BALL.black;
  }
}

Never:

ball.color || defaultColor

for canonical English-pool ball identity.
