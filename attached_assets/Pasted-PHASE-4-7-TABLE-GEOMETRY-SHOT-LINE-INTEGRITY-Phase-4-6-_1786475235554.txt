Phase 4.6 is deployed.

The rack rendering has improved, but the live training diagrams are STILL not sufficiently accurate.

THIS IS A TRAINING APPLICATION.

The diagrams must teach a player exactly how to reproduce a shot on a real English 8-ball table.

Do NOT change:
- adaptive engine
- ratings
- confidence
- match intelligence
- rules penalties
- mixed-mode allocation
- persistence
- navigation
- Sage–Teal theme

This patch is ONLY about:

1. Correct English-pool table marking geometry.
2. Correct baulk line / D / black-spot placement.
3. Reliable aim-line and potting-line rendering.
4. Exact drill-to-diagram consistency.

==================================================
