4. CUE BALL MUST BE HARD-CODED BY TYPE
==================================================

The cue ball must ALWAYS render off-white.

Canonical mapping:

cue:
#F2F0E8

red:
#B83E35

yellow:
#D6A52E

black:
#151918

Do not accept arbitrary fill colours for canonical ball types.

Implement one authoritative renderer function.

Conceptually:

function getCanonicalBallFill(group) {
  switch (group) {
    case "cue":
      return BALL_COLORS.cue;
    case "red":
      return BALL_COLORS.red;
    case "yellow":
      return BALL_COLORS.yellow;
    case "black":
      return BALL_COLORS.black;
    default:
      throw new Error("Unknown English pool ball group");
  }
}

Do NOT use:

ball.color || ...
ball.fill || ...
fallbackColor

for canonical English balls.

If a cue ball is marked as group/type "cue", it MUST render white/off-white regardless of any other field.
